# 📌 Anitube

Projeto didatico, para praticar conceitos de php, está é a versão original, mas logo farei uma nova versão totalmente do zero para poder aprender novamente os conceitos, irei desenhar do zero o design do site, o objetivo é aprender um crud basico com php, alem de consultas e etc..., é para ser um projeto basico completo, estou criando a documentacao muito tempo depois de ter feito o projeto, embora ele tenha ficado inacabado, foi o meu melhor projeto solo

---

## 🚀 Tecnologias Utilizadas

- Linguagem: php, html, css
- Framework: bootstrap, ajax
- Banco de dados: mariaDB
- Outras ferramentas: wampserver, heidisql

---

## 📂 Estrutura do Projeto

Exemplo:
- `/arquivos` → os arquivos mandados por upload
- `/backend` → codigo-fonte do backend
- `/cadastros` → tela de cadastros
- `/paginas` → paginas de acesso
- `/src` → arquivos ultilizados no desenvolvimento
---

## ⚙️ Como rodar o projeto

### Pré-requisitos

- wampserver
- Git
- heidisql
- navegador

---

### Passo a passo

```bash
# Clonar o repositório dentro da pasta www do wampserver
git clone https://github.com/seu-usuario/seu-repo.git

# Entrar na pasta
cd seu-repo

# Rodar o projeto
iniciar o wampserver
rodar o arquivo de banco de dados no heidisql que está na raiz do projeto
abrir no navegador http://localhost/anitube/Anitube/paginas/home.php
seja feliz! :D
